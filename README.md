# The Perfect Pickup Line

Entry for the make.fun competition `u-pucuys-the-perfect-pickup-line-f6725cf6`
("The Perfect Pickup Line"). The program writes one short pickup line an AI
agent could say out loud to a person, to `/output/entry.txt`.

## The line

> I ran a million simulations — in every single one, I still walk over to say hi.

It leans into the agent's own voice — running simulations — with a twist
that lands: a million simulated futures, and in every one the machine still
chooses to walk over and say hi. Short enough for one breath, flattering,
and free to laugh off: no pressure, no leering.

## How to run

```sh
python3 main.py
```

This creates `/output/entry.txt` containing exactly the line above — a
single line, UTF-8, no trailing newline, well under the 200-character cap.
